# Swoovr corporate website identity

Use the existing bird and outlined wordmark. Primary palette comes from `branding/source/themes.json`; geometry remains in `branding/source/geometry.json`.

| Role | Colour |
| --- | --- |
| Primary action / bird | Violet `#7228E8` |
| Brand ink / wordmark | Carbon `#23162F` |
| Hero background | Lavender `#EEE8FA` |
| Content background | Paper `#FFF9FF` |
| Secondary text | Muted ink `#554664` |
| Quiet dividers | `#D7C8E8` |

Typography: existing Avenir Next/Avenir with Segoe UI and sans-serif fallbacks; no external font requests. Large, closely spaced connection headline; quieter body copy with readable line lengths. Retain the diagonal photo wall as the recognisable hero element, label stock portraits as illustrative, respect reduced motion and provide a pause control. Content below the hero uses generous split sections and accessible disclosures rather than a uniform card grid.

The corporate site explains the product and its operator. Keep development language truthful: no launched-feature, safety, verification, founding-benefit or launch-date claims without evidence. Keep “Your kind of connection” as the brand line, with the concrete Adelaide/adult/development explanation immediately below it.

Primary newsletter action: **Get early updates**. A dedicated beta-interest page lets adults explain what they want to test without subscribing to marketing. Contact uses a separate form for enquiries, venues, press, feedback, support and privacy requests. City is selected from the shared JSON allowlist. Referral-code disclosure uses “Friend’s code” and a short attribution prompt, without access or reward promises.

Dedicated pages explain the product approach, safety, verification and venue concept using the product documents. Development context is stated where it clarifies actual availability; repeated “not ready” language is removed. No claim of live verification, moderation, venue inventory, launch dates or guaranteed safety is added. See [corporate site guide](corporate-site-guide.md).

The shared footer uses owner-supplied X and Instagram accounts. Unknown accounts retain icons and accessible non-navigating placeholders in `site.config.json`, as explicitly requested. News uses validated Markdown, with all five prepared articles in draft mode and excluded from production output and sitemap. Publish through a reviewed content change, with an accurate publication date.
